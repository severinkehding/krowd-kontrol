# Playtest Feedback Collection Plan

Records the feedback-collection plan for PRD 15 ("Release, Platform & Monetization")
REQ-3, covering both playtest rounds: the PoC ("Playable Alpha") demo and the Open
Beta demo. This is a **plan**, not the live form — the actual form (Google Form or
equivalent) is built and hosted outside this repo. See `MISSION.md`'s Out of Scope
section: no in-game telemetry/feedback infrastructure is built for this project.

## PoC ("Playable Alpha") Demo

- **Target playtesters**: 5-10 playtesters.
- **Minimum responses**: at least 5 responses.

Suggested questions:

1. How would you rate overall fun, 1-5?
2. How would you rate the difficulty ramp: too easy / about right / too hard?
3. Was it clear which ability countered which enemy colour? (yes / mostly / no)
4. What was confusing or frustrating?
5. What stood out most about the game?

## Open Beta Demo

- **Target playtesters**: 10-20 playtesters.
- **Minimum responses**: at least 10 responses.

Suggested questions (same core set as the PoC round, for comparability across
rounds):

1. How would you rate overall fun, 1-5?
2. How would you rate the difficulty ramp: too easy / about right / too hard?
3. Was it clear which ability countered which enemy colour? (yes / mostly / no)
4. What was confusing or frustrating?
5. What stood out most about the game?

Open Beta content added since the PoC round (bosses, room-pool system, etc.) may
warrant round-specific extra questions once that content exists — optional, and not
required to expand this list beyond what's above.

## Form Ownership

The actual form (Google Form or equivalent) is created and hosted outside this repo,
by the developer — not by the factory. This file tracks the plan only, not the live
form or its responses.
